# Forecast

Agent proposal · Not reviewed.

<p id="dm-return"></p>

A normalized forecast for a Place: provider update time, fetch time, source mode and a short series of periods.

## Identity and relationships {#identity-and-relationships}

The forecasts table is keyed by place\_id. There is no Forecast.id property. The outgoing event ID combines the place key and updatedAt; it identifies the event, not a separate Forecast.id.
