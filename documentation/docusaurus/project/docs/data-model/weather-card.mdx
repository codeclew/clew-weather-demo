# Weather card

Agent proposal · Not reviewed.

<p id="dm-return"></p>

## Identity and relationships {#identity-and-relationships}

weather\_cards is keyed by place\_id and GET /api/weather returns that key as id. Card forecast may be pending/null, unlike the required forecast property of a forecast.updated event.
