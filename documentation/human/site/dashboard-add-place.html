POST /api/places

Add a place and request its forecast

Documented start: HTTP · Dashboard · Dashboard POST /api/places

Whole process

  • This service’s part — Forward the place request

Services and processes

Handler-started sequence

  1. savePlace sends the incoming request body as JSON to Places POST /places and sets a 10-second abort timeout.
  2. If the fetch and JSON parsing succeed, Dashboard returns the Places status code and parsed JSON body.
  3. If the operation throws, Dashboard returns 503 with PLACES_UNAVAILABLE.

The handler refers to placesUrl; its value or provider was not resolved in this Work. The downstream route's source and deferred event path are described in Places create and Add a place.

Declared contract

The OpenAPI request body requires JSON cityId. It declares a Place response on 200 and error responses including 400, 415, 500, and 503. The handler itself forwards a downstream status/body and maps thrown failures to 503; this source does not establish that the declared request schema is enforced.

async function savePlace(request: FastifyRequest, reply: FastifyReply): Promise<void> {
  try {
    const response = await fetch(`${placesUrl}/places`, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(request.body), signal: AbortSignal.timeout(10000) })
    reply.code(response.status).send(await response.json())
  } catch {
    reply.code(503).send({ error: 'PLACES_UNAVAILABLE' })
  }
}
