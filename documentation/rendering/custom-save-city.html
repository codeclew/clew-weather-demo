1 · Literal lookup

Choose a retained City record

City(id) selects one of three literals: Oslo, Helsinki or Lisbon. An unmatched ID returns null. Latitude and longitude are stored directly in these records; this lookup does not calculate coordinates.

2 · Failure stays beside the step

Unsupported ID: return before Save

The inspected controller calls PlacesRepository.City(request.CityId). If the result is null, it returns BadRequest with UNSUPPORTED_CITY before the call to repository.Save.

This statement is bounded to this method's control flow. It does not establish whether middleware ran or whether a real request reached this code.

3 · Visible interaction boundary

A supported city proceeds to Save

For a non-null city, this controller awaits repository.Save(city, token), then returns Ok(city). That call is an implementation boundary in this fragment. Persistence success, the called implementation and Kafka delivery require additional evidence.
