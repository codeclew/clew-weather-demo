## Identity and relationships {#identity-and-relationships}

<ClewMarkdown text={"This supported-city reference is separate from saved places in PostgreSQL. City(id) selects one of the literals below; List and Save query or update the places table separately. An unknown ID returns null. The inspected Places controller responds with 400 UNSUPPORTED_CITY before calling Save; that branch does not save a city. These are retained static source facts, not an observed request or a live database dump."} />
