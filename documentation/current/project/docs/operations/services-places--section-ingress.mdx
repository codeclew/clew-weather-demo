# Places ingress contracts

<ClewPageContext />

Retained account · UNVERIFIED · UNASSESSED. Runtime behavior is not established by this export.

The controller exposes GET /places, POST /places, POST /places/&#123;id&#125;/refresh, GET /health, and GET /openapi.json. Listing returns the repository result; saving maps SavePlace.CityId and returns 400 UNSUPPORTED\_CITY for an unknown ID or saves and returns the Place; refresh returns 404 PLACE\_NOT\_FOUND for a missing ID or enqueues the place and returns 202 QUEUED. Health runs the repository's database ping and returns database READY. OpenAPI retrieval reads /app/contracts/places.openapi.json. The declared contract lists 200/500 for GET routes, 200/400/415/500 for save, and 202/404/500 for refresh; it requires cityId in the save body and declares the three supported IDs.
