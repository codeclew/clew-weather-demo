# Publish pending place requests

<ClewPageContext />

Retained account · STALE · UNASSESSED. Runtime behavior is not established by this export.

ExecuteAsync creates a producer and repeatedly calls PublishPending until cancellation, logging other exceptions as PUBLISH\_RETRY and waiting one second between attempts. Each publish opens a database transaction and selects one eligible unpublished row in created\_at order with FOR UPDATE SKIP LOCKED; no row returns without sending. Otherwise it extracts the place ID from the payload, awaits a keyed send to weather.place-requested, marks the row published, and commits. A broker send followed by a transaction failure or crash can leave the row eligible for replay. The Dashboard and Forecasts topic mappings are agent-proposed; subscription, downstream processing and hosted-service activation remain unverified.
