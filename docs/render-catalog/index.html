Codeclew rendering research · actual demo repository

Rendering catalogue, from real repositories

Browse pages, isolated blocks and diagrams produced by Codeclew. The examples use source-built Codeclew 31a5598. Weather is used wherever its real source admits the renderer; Petclinic supplies Java flow and Kotlin accessor examples. Existing accepted descriptions and provenance are preserved. New authored examples state their review status.

This gallery is a research wrapper. Block previews are read-only excerpts of the existing reader, with disclosures opened. The full example retains interactive source links and complete provenance. Of the original 18 gaps, 15 now have real examples, two remain open, and the unsupported UpdateDeal prototype is listed separately. The 15 include the OperationAnswer family; its richer refresh draft is explicitly unreviewed.
